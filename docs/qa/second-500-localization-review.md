## Scanner refinement

The audit now recognizes narrowly scoped typed legal protocol values, typed status-selector values, common technical JSX control attributes, and `mailto:` templates. It distinguishes known moderation action codes supplied to an onClick handler from independently rendered button text. Remaining ambiguous findings stay in `review`; no blanket exemption for plain strings, object fields, or template literals.

## Important boundaries

- Never translate values sent to the backend for `status`, `action`, `role`, `documentType`, `changeClass`, or `userAction`. Only labels are localized.
- The existing server-supplied error messages and data-driven content are **not** proven translated by this source audit. The separate backend/data contract and browser audit must validate them.
- The language catalogs include EN, DE, FR, ES and EL, with preserved interpolation placeholders.
- No claim is made here that CI, a browser verification or a fresh source audit has passed. A passing final-commit run and the original-ID reconciliation are required before merging.
