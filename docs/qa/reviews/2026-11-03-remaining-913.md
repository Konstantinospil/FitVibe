## Detector refinements

The AST audit must preserve user-visible text in JSX, accessible labels, notifications and data-contract fields. The following are **not** text to translate when their AST context proves their function:

1. Standardized ARIA state values (`aria-hidden`, `aria-live`, `aria-current`), but **not** `aria-label` or `aria-description`.
2. Native SVG geometry/paint attributes (`viewBox`, `strokeWidth`, `path d`, etc.), without suppressing user-visible `<title>` text.
3. Hex colors, CSS variables/dimensions and protocol-only formatting options.
4. The severity type argument of `showToast(type, message)`, while retaining the second argument as UI text.
5. Strings inside the already-localized minimal English resource map `minimalCommon`.
6. Interpolation-only templates with no static natural-language content.

Add scanner regression tests for positive and negative cases; avoid generic exclusions by file path or by text that could hide future UI labels.
