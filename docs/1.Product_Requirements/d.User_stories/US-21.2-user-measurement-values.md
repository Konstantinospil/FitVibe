## User Story

**As a** authenticated user  
**I want** to record and update my biometric and performance measurement values  
**So that** I can track my progress consistently over time

## Acceptance Criteria

- [US-21.2-AC01](../e.Acceptance_Criteria/US-21.2-AC01.md): Record enabled measurement values
- [US-21.2-AC02](../e.Acceptance_Criteria/US-21.2-AC02.md): Historical value identity and timestamps
- [US-21.2-AC03](../e.Acceptance_Criteria/US-21.2-AC03.md): Canonical unit semantics

## Scope Boundary

This story owns value recording for definitions already enabled for the user. Search, add/remove visibility and broader profile presentation remain under US-21.3. Derived value calculation remains under US-21.4.
