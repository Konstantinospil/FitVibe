## User Story

**As a** authenticated user  
**I want** to use deterministic derived measurements based on recorded source measurements  
**So that** I can see meaningful calculated indicators without losing the original data

## Acceptance Intent

- derived definitions identify source measurements and calculation semantics;
- derived values are deterministic for the same source inputs;
- updates to source values refresh the derived result;
- raw/source measurements remain authoritative and are not overwritten by the derived value.

Canonical AC files will be created or marked verified only after the live implementation is compared with this contradiction-free target documentation. This story is therefore product scope, not automatically a future implementation issue.
