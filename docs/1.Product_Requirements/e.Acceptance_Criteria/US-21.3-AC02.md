## Criterion

A user can add or remove a canonical measurement from profile presentation without creating a new definition or changing historical values. The selection persists through the canonical visibility endpoint.

## Evidence Required

- add/remove invokes the existing measurement visibility API;
- UI state updates only after the persistence request succeeds;
- controls are keyboard-operable buttons with programmatic pressed state;
- selection does not modify catalogue identity or recorded values.
