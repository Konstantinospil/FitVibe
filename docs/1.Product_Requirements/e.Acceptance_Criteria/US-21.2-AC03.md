## Criterion

A measurement value is entered and persisted according to the measurement definition's canonical measurement system and granularity. Metric/imperial catalogue metadata may define equivalent validation ranges, but the value-write API does not silently convert or reinterpret a submitted number.

## Evidence Required

- enabled definitions expose their canonical `measurementSystem` and `granularity`;
- frontend value entry displays the definition granularity;
- backend range validation uses the definition's canonical system;
- the write contract persists the supplied numeric value without hidden conversion.
