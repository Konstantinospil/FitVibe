## Criterion

Recorded measurement values reference the stable catalogue definition UUID. Presentation metadata changes, including translated labels, must not replace the definition row or invalidate historical values.

Catalogue records are not hard-deleted through the measurement API. Historical values remain attributable to the same definition identity.

## Evidence Required

- value tables reference measurement-definition UUIDs by foreign key;
- label/translation updates modify presentation metadata without changing definition identity;
- no measurement-definition hard-delete endpoint is exposed;
- tests verify value persistence by attribute ID and translation updates independently of value history.
