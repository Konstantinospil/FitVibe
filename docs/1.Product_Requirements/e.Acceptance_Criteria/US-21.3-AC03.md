## Criterion

The authenticated profile presents the user's enabled biometric and performance measurements from the canonical measurement API. When a latest value exists, the value and definition granularity are shown; otherwise an explicit no-value state is shown.

## Evidence Required

- Profile page loads enabled biometric and performance definitions;
- hidden definitions are not rendered because the canonical enabled-only API is used;
- loading, empty and error states are explicit;
- presentation uses semantic definition/value markup and remains keyboard/assistive-technology compatible.
