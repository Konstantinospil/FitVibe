## Criterion

Every measurement definition identifies its category, unit type, display granularity, canonical measurement system, and validation range. Where a unit is convertible between metric and imperial systems, both validation ranges are persisted from one canonical creation input rather than creating duplicate definitions for the same semantic measurement.

Non-convertible unit types such as ratios, counts, time, power, and percentages preserve equivalent numeric bounds across presentation systems.

## Evidence Required

- schema/controller validation limits unit types and measurement systems to supported values;
- creation service stores metric and imperial min/max representations from a single definition;
- tests cover representative length and weight conversion plus invalid min/max ordering;
- seeded definitions expose both system ranges without separate metric/imperial semantic duplicates.
