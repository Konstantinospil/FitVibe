## Criterion

Biometric and performance measurement definitions are global system-owned catalogue records. Authenticated users may discover and select definitions, but only administrators may create new global definitions.

Each definition has a stable UUID and stable machine key. Duplicate semantic definitions are prevented by normalized uniqueness so insignificant label casing or whitespace cannot create a second definition.

## Evidence Required

- measurement create routes require the canonical access-token middleware and the `admin` role;
- non-admin catalogue creation is rejected before the controller executes;
- `bio_attributes.normalized_key` and `perf_attributes.normalized_key` have unique database constraints;
- service tests prove normalized duplicate detection;
- catalogue creation records an audit event identifying the admin actor and created definition.

## Ownership and Provenance Decision

Catalogue definitions are **system-owned**, not user-owned. A `created_by_user_id` column is intentionally not added because it would imply ownership semantics that do not apply to a global catalogue. Administrative actor provenance is retained in the immutable audit log.
