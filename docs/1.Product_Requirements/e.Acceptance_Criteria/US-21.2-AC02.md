## Criterion

Every recorded measurement value is user-owned, references the stable measurement-definition UUID, and retains an explicit measurement timestamp separate from creation time. Adding a later value does not overwrite earlier active history.

## Evidence Required

- value tables persist `user_id`, `attribute_id`, `value_number`, `measured_at`, and `created_at`;
- inserts create new value rows rather than updating the previous row;
- latest-value queries deterministically select by measurement timestamp and creation timestamp;
- the frontend sends the user-selected measurement timestamp.
