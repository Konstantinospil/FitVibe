## Criterion

An authenticated user can record a value only for a measurement definition currently enabled for that user. Derived definitions remain read-only. The server validates values against the canonical definition range before persistence.

## Evidence Required

- hidden/non-default definitions without an enabled selection are rejected;
- enabled/default definitions accept valid values;
- out-of-range values are rejected by the backend;
- derived values cannot be written directly;
- Settings → Progress exposes value entry only for enabled, non-derived definitions.
